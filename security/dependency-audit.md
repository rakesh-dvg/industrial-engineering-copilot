# Dependency audit

Run from a fresh clone when preparing a release or submission review.

## Python (backend)

```powershell
cd backend
pip install -e ".[dev]"
ruff check .
bandit -r app -f txt -o ../security/bandit-report.txt
pip-audit
```

`bandit-report.txt` in this folder is generated by Bandit against `backend/app/` (tests excluded via Bandit config).

## Node (frontend)

```powershell
cd frontend
npm audit
npm run lint
```

## CI parity

GitHub Actions runs `ruff check` and `pytest` on backend; `npm run lint`, test, and build on frontend — see [docs/cicd.md](../docs/cicd.md).

Record the date and command versions in your review notes when refreshing reports.
